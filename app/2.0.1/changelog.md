# SWARMUX changelog

## [2.0.1] - 2026-11-28

### New
- **SWARMUX green.** The focused pane, highlights and controls use the SWARMUX accent in the default dark and light themes.
- A cleaner welcome and agents list: no beta badge, shorter hints.

## [2.0.0] - 2026-11-28
<!-- spotlight -->

### New
- **SWARMUX 2 is a native app.** A GPU-drawn window for terminals and coding agents: spaces, tabs, splits, an agents list that shows who is working, blocked or done, and layouts and mods you can change while it runs.
- **Your terminals outlive the window.** They run in swarmux-core, so closing or updating SWARMUX keeps them going, and after a reboot each pane comes back in its last folder.
- **Other machines, side by side.** Add an SSH machine or WSL and its spaces run their terminals there.
- **No telemetry.** SWARMUX sends no usage data; it only checks GitHub for updates. Feedback opens a GitHub issue for you to review.
