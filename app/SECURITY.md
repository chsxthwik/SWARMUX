# Security

Report vulnerabilities privately through [GitHub's Report a vulnerability](https://github.com/chsxthwik/SWARMUX/security/advisories/new). Don't post exploit details in a public issue.

Include the SWARMUX version, OS, what you found, steps to reproduce it, and the impact. A small proof of concept helps. Remove secrets and personal data from logs.

Only the latest release is supported.

For how SWARMUX handles trusted mods, updates and privacy, see [security and privacy](docs/security.md).
